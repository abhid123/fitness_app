

# Fitness Website

A fitness website built using React, Rapid API, and Material UI. The platform allows users to explore various exercises and view YouTube videos related to each exercise. 

## Project Link
https://behelthy.netlify.app/

## Features 
* Browse exercises fetched from the Rapid API.

* Detailed information about each exercise.

* YouTube integration for exercise demonstrations.

* Responsive design using Material UI.

## Tech Stack

* React - JavaScript library for building user interfaces.
* Material UI - Component library for fast and easy design.
* Rapid API - Used for fetching exercise data.
* YouTube API - Displays exercise videos on user interaction.

## Installation

1. Clone the repository:
   ```cmd
   git clone https://github.com/abhid123/fitness-website.git
2. Navigate to the project directory:
   ```bash
   cd fitness-website
2. Install the dependencies:
   ```bash
   npm Install
  - `@emotion/react`
- `@emotion/styled`
- `@mui/icons-material`
- `@mui/material`

- `react`
- `react-dom`
- `react-horizontal-scrolling-menu`
- `react-loader-spinner`
- `react-router-dom`
4. Start the development server:
   ```bash
    npm run dev 

## How It Works 
1. Home Page: Users can browse different exercise categories.

2. Exercise Page: Clicking on an exercise displays more details and related videos.

3. Video Integration: YouTube videos are fetched based on the selected exercise.
